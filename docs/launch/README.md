# Zat — launch material

Publication-quality drafts for launching Zat. Edit freely; nothing here is
generated at build time.

No metrics, customers, funding, partnerships or traction are claimed anywhere
in this folder, because none exist yet. Please keep it that way — the product's
entire argument is about not overstating things.

| File | What it is |
|---|---|
| `positioning.md` | One-liner, short and long descriptions, both pitches |
| `announcement.md` | Launch post, Product Hunt, X, Instagram |
| `emails.md` | Creator invitation, welcome, early-access confirmation |
| `press.md` | Boilerplate and FAQ |
| `principles.md` | Product principles and demo talking points |
